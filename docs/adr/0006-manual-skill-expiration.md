# 过期标记独立保存，启用仍以软链为准

过期由用户按“来源＋技能名”手动标记，保存于现有 SQLite 文件的独立 `expired_skills` 表，不依赖可重建的来源、技能索引行。来源更新和重启不清除标记；与软链表达启用状态不同，软链缺失无法区分“普通关闭”和“过期”，因此保留独立的用户元数据，延续 ADR-0001 对非派生状态的预留。

标记过期先停用技能并移除对应受管软链，成功后保存标记；若软链路径存在冲突则保留原内容、报告失败，不标记过期。保存失败时技能保持关闭，界面报告错误。过期技能的启用开关置灰，来源批量启用跳过它，来源开关按未过期技能汇总，全部过期时来源开关也不可操作。取消过期只恢复可操作性，不自动启用。技能详情始终可查看。

SQLite 中的索引可以重建，但过期标记是用户数据，不能从技能目录重建；数据库不可用时启用操作及过期标记操作报告错误，查看技能和停用操作仍可用。技能消失后再以相同来源和名字出现，仍沿用此前标记，避免更新自动解除用户的禁用决定。

详情顶栏固定显示技能声明名称（缺失则使用目录名）、总字数及过期开关。总字数统计当前 `SKILL.md` 全文的非空白 Unicode 字符，包含声明块、Markdown 标记及代码，不包含引用文件；统计在读取文件时完成，不随绘制重复计算。
