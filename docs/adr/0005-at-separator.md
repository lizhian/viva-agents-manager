# 安全名与启用软链使用单个 @ 分隔

来源 `owner/repo` 对应 `owner@repo`，启用软链对应 `vam@owner@repo@skill`。这取代 ADR-0004 的三下划线方案：单个 `@` 更简洁，且不属于仓库 owner/repo 的有效字符，保留明确边界而无需限制下划线。

技能名及本地来源名保留 `@`，取消三下划线和边界下划线限制；原始名称不被改写。界面仍显示 `owner/repo`。

沿用已确认的迁移与冲突保护规则，启动时兼容 `_@_` 和 `___` 两种旧来源目录、受管软链，并支持中断后的重试。只处理指向对应技能库目录的旧软链，保持启用状态；冲突保留原内容并报告错误。迁移仍以来源为单位，索引从迁移后的磁盘重建。
