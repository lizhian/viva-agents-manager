# 网址来源目录以可读域名为主，仅新安装使用

纯哈希目录无法让用户从路径辨认技能来源。新安装的普通 HTTPS 根站点以域名作为安全名，例如 `https://archify.si` 对应 `skills/archify.si/archify`；HTTP 来源或带子路径、参数、片段的复杂网址使用「域名＋可读摘要＋短哈希」，在保持可读性的同时区分不同来源，命名不依赖安装顺序。GitHub 的 `owner@repo` 命名保持不变。

沿用 [ADR-0008](0008-url-skill-sources.md) 的磁盘元数据保存完整原地址，更新仍使用原地址。调整其中的判重规则：根网址的空路径与 `/` 视为同一来源；其余协议、路径、查询参数、片段差异继续保留。

仅新安装使用新命名，已有 `url-<完整哈希>` 目录、启用链接和过期标记不迁移。新旧格式均须恢复来源身份、支持更新，并按来源地址跨命名格式判重；可读目录名不再作为唯一的来源身份依据。选择兼容旧格式而不自动迁移，是为了保持现有安装路径与引用稳定。
