# 启用状态以 agent 目录中的实际软链为准

启用一个技能，是在 `~/.agents/skills` 创建指向技能库目录的软链，名称为 `vam@来源安全名@技能名`；例如 `vam@mattpocock@skills@grilling`。前缀区分本应用管理的技能，来源安全名沿用 ADR-0002，避免不同来源的同名技能占用同一个路径。

这取代 ADR-0001 中“启用状态后续存数据库”的预想：只有对应软链指向当前技能库的有效技能时才视为启用，重启从磁盘恢复，不额外保存一份可能与软链漂移的布尔状态。关闭只移除指向该技能的软链；已有文件、目录或指向其他位置的软链一律保留并报告冲突。批量操作保留成功项，界面显示实际结果。

来源开关控制该来源全部技能，包括搜索隐藏的技能；部分开启时显示“部分”，点击则全部开启，再点击全部关闭。来源更新保留仍存在技能的启用状态，清理已移除技能的受管软链，新技能默认关闭。更换命名或启用位置需要考虑已有链接的迁移。
