# 网址来源以短安全名与磁盘元数据保存身份

技能来源支持 HTTP 与 HTTPS 网址。网址来源使用短且稳定的安全名，在来源目录内保存原安装地址元数据；启动扫描与索引重建从磁盘恢复来源身份，更新继续使用原地址。现有来源目录和启用软链保持兼容。

这扩展了 [ADR-0005](0005-at-separator.md) 的安全名约定：网址来源无需从目录名直接还原地址，同时保留 [ADR-0001](0001-skills-on-disk-sqlite-as-index.md) 的磁盘权威原则。把完整网址可逆编码为目录名会遇到长度限制；只用域名则无法区分同一站点的不同来源，因此选择目录内元数据，而非把原地址只存入 SQLite。

网址判重采取保守归一化，保留协议、路径、查询参数和片段的差异，不根据重定向合并来源。明确等价的 GitHub 仓库根地址与 `owner/repo` 共用来源身份；带分支、子路径或其他参数的地址保留独立身份。重复安装同一来源应被阻止。

添加来源时输入网址即可，不解析整条 `npx skills add` 命令。网址来源与现有远程来源一样支持重启后识别、更新（含全部更新）、启用及删除。

[ADR-0009](0009-readable-url-source-names.md) 补充可读目录命名与旧格式兼容，并调整根网址末尾斜杠的判重规则。
