# AGENTS.md 由指令片段生成

AGENTS.md 功能管理平铺的指令片段，自动将启用片段的正文合并到 `~/.agents/AGENTS.md`。目标文件是生成结果，不能同时作为片段内容的来源；首次接管时，将已有内容导入为一个已启用的「原有指令」片段，以保留用户指令。

合并顺序遵循列表中的手动排列，搜索和标签筛选不改变合并顺序。只拼接正文，片段之间留一个空行，不生成名称或标签；空正文不贡献输出，非空结果保留末尾换行，全部关闭时写出空文件。开关、正文与顺序变化自动更新输出，正文编辑沿用自动保存节奏，写入失败明确显示错误。

接管后若检测到目标文件被外部修改或删除，暂停覆盖。恢复生成必须由用户明确选择：「将外部文件导入为关闭的片段，再重新生成」或「丢弃外部修改，重新生成」。选择之前保持暂停。相比直接覆盖或将手写内容长期混入生成文件，这使片段成为明确的内容来源，并避免静默丢失外部修改；代价是外部改动需要显式处理后才能继续生成。

新建的片段以及外部修改恢复时导入的片段默认关闭，首次接管的「原有指令」例外。

## 界面范围

保留新建、标题直接编辑、启用开关、拖拽排序、标签、顶栏常驻搜索框、格式工具栏、源码/预览/分栏与自动保存。整体沿用 motty 的笔记布局，字体、间距、颜色与按钮使用本应用 Skills 页的样式。

不提供 Markdown 文件导入、文件夹、置顶、片段行的更多菜单和独立窗口；不引入链接文件/文件夹、导出、关联主机、跨设备同步或终端侧栏嵌入。

## 本地保存与生成恢复

片段库以独立的版本化 JSON 快照保存到 `~/.viva-agents-manager/agentsmd/library.json`，正文和开关一起提交；视图状态单独保存。相比为每个正文建立文件并另外维护元数据，单个快照避免了正文与开关提交一半时的不一致，且不把技能的 SQLite 派生索引变成片段内容来源。这一选择仅适用于指令片段，不改变 ADR-0001 的技能存储。

版本 2 使用平铺列表。读取版本 1 时，按原有的合并遍历顺序展开文件夹，保留全部片段及其 ID、正文、标签和启用状态，忽略置顶的展示顺序；首次成功保存时移除目录与置顶元数据。迁移不改变生成内容，失败时不覆盖源文件。

写出前持久化上次输出摘要与本次生成意图，原子替换目标文件后再确认摘要。启动时据此恢复被中断的生成。外部检查只在启动和生成前执行，不运行后台轮询。
