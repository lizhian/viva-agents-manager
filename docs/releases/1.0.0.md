# Viva Agents Manager v1.0.0

首个正式版本，管理本机的 agent 技能与 AGENTS.md 指令片段。

- Skills：管理技能来源，安装和更新技能，按来源或单个技能启用，标记过期技能，查看技能文档与关联文件。
- AGENTS.md：新建和编辑指令片段，通过开关启用、拖动排序，自动合并生成 `~/.agents/AGENTS.md`。
- 提供标签、搜索、Markdown 工具栏、源码/预览/分栏、自动保存，以及外部修改的暂停与恢复处理。
- 界面支持浅色与深色主题；当前提供 Skills 和 AGENTS.md 两个页面。

## 下载

每个平台均提供 x86_64（amd64）与 ARM64 两种架构。macOS 需要 13.0 或更高版本，Windows 需要 Windows 10 / Server 2016 或更高版本。

| 系统 | 安装包 | 其他格式 |
| --- | --- | --- |
| macOS | `.dmg` | `.zip` 应用包 |
| Windows | `-setup.exe` | `.zip` 可执行文件 |
| Linux | `.deb` | `.tar.gz`（含安装脚本） |

可使用 `SHA256SUMS` 校验下载文件。macOS/Windows 安装包未配置开发者证书签名或公证，系统可能要求用户手动允许打开。

包由 Viva v0.6.1 构建。跨平台产物由 GitHub Actions 生成；尚未在全部六种系统/架构组合的真实设备上进行运行验证。
