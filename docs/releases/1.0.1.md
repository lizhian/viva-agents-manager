# Viva Agents Manager v1.0.1

修复 macOS 安装版从 Finder 启动后，即使已经安装 Node.js，安装技能时仍提示“未找到 npx”的问题。

- 修正登录 shell 输出中 PATH 的解析，正确找到 nvm、mise、asdf 等工具配置的 Node.js / npx。
- 增加最小 PATH 环境下的安装流程回归测试。

提供 macOS、Windows、Linux 的 x86_64（amd64）与 ARM64 安装包及压缩包，附带 `SHA256SUMS`。

macOS 需要 13.0 或更高版本；安装包未配置开发者证书签名或公证。已通过自动化检查，尚未在全部平台进行真机安装验证。
