# Viva Agents Manager v1.1.0

支持从 HTTP(S) 网址安装技能来源，例如在安装框输入 `https://archify.si`。

- 网址来源支持重启后识别、更新、启用及删除；等价的 GitHub 仓库根网址与 `owner/repo` 合并判重。
- 新安装的普通 HTTPS 站点使用可读域名目录，例如 `skills/archify.si/archify`；复杂网址使用域名、可读摘要与短哈希。已有哈希目录保持兼容，不自动迁移。
- 根网址有无末尾 `/` 视为同一来源，同名目录冲突时保留原内容并报告错误。
- 增加带确认的来源删除操作，入口位于详情顶栏最右侧的垃圾桶图标。
- 修复 AGENTS.md 详情预览区滚动方向相反的问题，包含分栏同步滚动。

提供 macOS、Windows、Linux 的 x86_64（amd64）与 ARM64 安装包及压缩包，附带 `SHA256SUMS`。

macOS 需要 13.0 或更高版本；安装包未配置开发者证书签名或公证。已通过自动化检查，尚未在全部平台进行真机安装验证。
