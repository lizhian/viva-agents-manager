# VAM icon concepts

Four editable SVG concepts and transparent PNG exports at 1024, 256, 32 and 16 pixels.

1. **Geometric V** — cream and mint V on deep ink; minimal geometric identity.
2. **Skill cabinet** — layered skill cards in a warm terracotta organizer; dimensional illustration.
3. **Agent network** — modular agents routed through a blue central hub; engineering diagram style.
4. **Retro console** — cream desktop terminal with a green prompt; playful retro computing.

`comparison.png` is the selection sheet, with 48/32/16 pixel samples. Geometric V (01) is the selected application icon; canonical assets are `../app-icon.svg` and `../app-icon.png`. All designs are original vector artwork; SVG sources use paths and shapes without external assets. The comparison sheet's labels use system fonts; individual icons contain no font dependencies.
